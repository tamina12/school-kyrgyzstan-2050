
# Кыргызстан — 2050 🌿

**Молодёжь за экологическое будущее**

Учебный веб-проект об экологических проблемах Кыргызстана и действиях,
которые помогают беречь окружающую среду.

## Возможности сайта

- Адаптивный дизайн для компьютеров, планшетов и телефонов.
- Разделы об экологических проблемах и возможных решениях.
- Эко-чеклист с индикатором выполнения.
- Демонстрационный эко-помощник с готовыми ответами.
- Персонажи Тамина и Байастан.
- Ссылки на официальные экологические источники.

## Структура файлов

- `index.html` — содержание сайта.
- `style.css` — оформление и адаптация экранов.
- `script.js` — меню, чеклист и эко-помощник.
- `images/eco-team.png` — изображение персонажей.

## Как запустить

1. Помести все файлы в репозиторий GitHub.
2. Создай папку `images`.
3. Добавь в неё изображение `eco-team.png`.
4. Открой Settings → Pages.
5. Выбери Deploy from a branch.
6. Выбери ветку `main` и папку `/(root)`.
7. Нажми Save.

## Важно

Эко-помощник использует заранее подготовленные ответы.
Он не подключён к настоящей ИИ-модели.

Проект предназначен для обучения и экологического просвещения.
Проверяй статистику и факты по официальным источникам.
